# 13 — Reglas para agentes de IA

- Leer primero `0_Vision/2_Alcance_Semana1.md` y `0_Vision/1_Vision_Producto.md`.
- No ampliar el alcance.
- No implementar scoring, casos, IA ni bases de datos futuras.
- No volver obligatorios GitHub Actions, runners o servicios adicionales.
- Mantener región y SKU parametrizados.
- Favorecer Managed Identity.
- Mantener un solo entorno integrado para cinco personas.
- Antes de editar un contrato, actualizar OpenAPI, pruebas y trazabilidad.
- Si una decisión pertenece a Semana 2, marcarla como pendiente y no inventarla.
