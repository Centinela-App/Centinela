# 16 — Checklist anti-caos

Antes de integrar un cambio:

- [ ] Deriva de `0_Vision/2_Alcance_Semana1.md` o es una decisión mínima de implementación.
- [ ] No agrega scoring, casos, IA ni persistencia futura.
- [ ] No introduce un servicio Azure no necesario.
- [ ] No fija región o tamaño que deberían ser parámetros.
- [ ] No crea otra infraestructura completa para un integrante.
- [ ] No contiene secretos.
- [ ] Respeta la separación staging/production.
- [ ] Mantiene Storage privado.
- [ ] Actualiza pruebas y documentación relacionadas.
- [ ] No define el contrato de Semana 2 sin su documento específico.
