# 17 — Definition of Done de Semana 1

Una issue está terminada cuando:

- Cumple sus criterios de aceptación.
- Las pruebas asociadas pasan.
- No expone secretos.
- Mantiene mínimo privilegio.
- No amplía el alcance.
- Incluye evidencia.
- La documentación relacionada está actualizada.

La Semana 1 está terminada cuando además:

- La infraestructura puede destruirse y reconstruirse por script.
- Analista no puede modificar recursos.
- Una transacción válida recibe acuse y queda almacenada.
- Una transacción inválida se rechaza correctamente.
- La API tolera la retirada de una instancia durante la prueba.
- La carga documental funciona.
- La cola fue escrita, leída y limpiada.
- Storage no tiene acceso público.
- Producción y staging tienen configuración separada.
- El entorno vuelve a una instancia o se destruye para controlar costos.
